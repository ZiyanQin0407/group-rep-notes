# Notes on Group Representation Theory
These notes grew out of my personal study of group representation theory.

## About These Notes
While standard textbooks (such as Serre’s Linear Representations of Finite Groups) provide an excellent foundation, I found that the transition from classical character theory to the modern module theoretic and categorical perspectives was often scattered across different sources.
